# BioSolver - Telegram Mini App для решения биологических задач

🧬 **Решай биологические задачи в 3 клика, а не за 3 минуты**

## 📋 Описание

BioSolver - это Telegram Mini App, который помогает преподавателям и репетиторам по биологии быстро создавать красивые, структурированные решения задач.

### ✨ Возможности MVP

- **Генетика**: Моно- и дигибридное скрещивание с таблицей Пеннета
- **Биосинтез белка**: ДНК → иРНК → Белок с автоподстановкой
- **Экологическая пирамида**: Калькулятор правила 10%
- **Специальная клавиатура**: Нуклеотиды, генетические символы, индексы

## 🛠️ Технический стек

### Frontend
- React 18 + Vite
- Tailwind CSS
- html2canvas (для экспорта в изображения)

### Backend
- Python 3.9+
- Aiogram 3.x (Telegram Bot API)
- FastAPI (опционально, для расширения функционала)

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- Python 3.9+
- Telegram Bot Token ([получить у @BotFather](https://t.me/BotFather))

### Установка Frontend

```bash
cd frontend

# Установка зависимостей
npm install

# Запуск режима разработки
npm run dev

# Сборка для продакшена
npm run build
```

### Установка Backend

```bash
cd backend

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Копирование .env файла
cp .env.example .env

# Редактирование .env (укажите ваш токен бота и URL)
# TELEGRAM_BOT_TOKEN=your_token_here
# WEBAPP_URL=https://your-domain.com

# Запуск бота
python bot.py
```

## 📱 Настройка Telegram Bot

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. В @BotFather настройте Menu Button:
   - Команда `/setmenubutton`
   - Выберите вашего бота
   - Укажите URL вашего фронтенда (например, `https://your-domain.com`)

Или используйте кнопку в самом боте после команды `/start`.

## 🎯 Пользовательский сценарий

1. Пользователь открывает бота и нажимает `/start`
2. Нажимает кнопку "Запустить BioSolver"
3. Выбирает тип задачи (например, "Моногибридное скрещивание")
4. Заполняет поля с помощью специальной клавиатуры
5. Нажимает "Сформировать решение"
6. Отправляет готовое решение ученику в Telegram
