# Quiz Bot

Телеграм-бот для создания и прохождения тестов (соло и групповой режим).

## Быстрый старт

### 1. Создай бота у @BotFather и получи токен

### 2. Скопируй .env.example в .env и заполни
```bash
cp .env.example .env
# Вставь BOT_TOKEN и BOT_USERNAME
```

### 3. Запусти одной командой
```bash
docker compose up -d
```

Порядок запуска автоматический:
- сначала стартуют `db` и `redis`
- затем `migrate` накатывает миграции
- затем `bot` запускается

### 4. Проверь логи
```bash
docker compose logs -f bot
```

---

## Команды

| Команда | Описание |
|---|---|
| `/start` | Главное меню, список квизов |
| `/start quiz_ID` | Запуск квиза по deep link |
| `/quiz_ID` | Меню редактирования квиза |

## Формат файла с тестами (.txt / .docx / .pdf)

```
Столица Франции?
=
#Париж
=
Лондон
=
Берлин
=
Мадрид
+
Сколько дней в високосном году?
=
365
=
#366
=
364
```

- `+` — разделитель между вопросами
- `=` — разделитель между вариантами ответа
- `#` — правильный ответ (ставится в начале строки)

## Остановка

```bash
docker compose down          # остановить, данные сохранятся
docker compose down -v       # остановить и удалить данные БД
```
