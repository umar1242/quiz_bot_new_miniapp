# Калькулятор решёток Пеннета

## Описание
Интерактивный калькулятор для Telegram Mini App, поддерживающий все типы наследования генов.

## URL доступа
- Основной интерфейс: `/punnett`
- Тесты: `/static/punnett/test.html`

## Поддерживаемые типы наследования

### 1. Независимое наследование (Менделевское)
- Моногибридное скрещивание (1 ген) → решётка 2×2
- Дигибридное скрещивание (2 гена) → решётка 4×4
- Все гаметы образуются в равных долях (25% каждая)

### 2. Аутосомное сцепление БЕЗ кроссинговера (полное сцепление)
- Дигетерозигота образует только 2 типа гамет (по 50%)
- Решётка 2×2 вместо 4×4
- Расщепление 3:1 (вместо 9:3:3:1)

### 3. Аутосомное сцепление С кроссинговером (неполное сцепление)
- 4 типа гамет, но с РАЗНЫМИ частотами
- Некроссоверные гаметы: (100% - crossover%) / 2
- Кроссоверные гаметы: crossover% / 2
- Решётка 4×4 с весами в каждой клетке

### 4. X-сцепленное наследование
- Без кроссинговера: решётка 2×2
- С кроссинговером (только у самок XX): решётка 4×2
- У самцов (XY) кроссинговер НЕ возможен

### 5. Y-сцепленное (голандрическое) наследование
- Только от отца к сыновьям
- Простейшая схема 1×1

## Примеры использования

### Пример 1: Моногибридное скрещивание
```
Тип: Независимое
Мать: Aa
Отец: Aa
Результат: 25% AA, 50% Aa, 25% aa
```

### Пример 2: Дигибридное скрещивание
```
Тип: Независимое
Мать: AaBb
Отец: AaBb
Результат: 9:3:3:1 (фенотипическое расщепление)
```

### Пример 3: Сцепление с кроссинговером 20%
```
Тип: Аутосомное сцепление (с кроссинговером)
Конфигурация: Цис (AB/ab)
Мать: AB/ab
Отец: AB/ab
Частота кроссинговера: 20%

Гаметы каждого родителя:
- AB: 40% (0.4)
- ab: 40% (0.4)
- Ab: 10% (0.1)
- aB: 10% (0.1)

Фенотипическое расщепление:
- A_B_: ~66%
- A_bb: ~9%
- aaB_: ~9%
- aabb: ~16%
```

### Пример 4: X-сцепленное наследование
```
Тип: X-сцепленное
Мать: X^AX^a
Отец: X^AY

Результат:
- Дочери: 50% X^AX^A (нормальные), 50% X^AX^a (носители)
- Сыновья: 50% X^AY (нормальные), 50% X^aY (affected)
```

## Форматы ввода генотипов

### Аутосомные гены
- Простой формат: `AaBb` (пары аллелей подряд)
- Со сцеплением: `AB/ab` (хромосомы разделены `/`)

### X-сцепленные гены
- Женщина (XX): `X^AX^a` или `X^AX^A`
- Мужчина (XY): `X^AY` или `X^aY`

### Y-сцепленные гены
- Только мужчины: `Y`

## Проверка корректности
- Сумма всех вероятностей должна быть 100%
- Валидация входных данных
- Unit tests доступны по адресу `/static/punnett/test.html`

## Интеграция с Telegram
Для экспорта результатов используется `tg.sendData()`, который отправляет данные обратно в бот.
